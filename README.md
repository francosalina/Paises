# 03 - BD2: Base de datos de países y CRUD

- **Base de datos:** `paises_7A`
- **Tablas:** `paises` (`pais_id`, `pais_descripcion`) y `provincias` (`pro_id`, `pais_id`, `pro_descripcion`)
- **Datos cargados:** Países de Latinoamérica y provincias de Argentina (`pais_id = 1`).
- **Operaciones:** CRUD sobre `paises` y consulta Master-Detail de países con sus provincias en `crud_paises.sql`.
